# All The Way - Courtside

Basketball drill library (188 drills with court diagrams) and an on-the-fly practice planner. Installable web app that works offline.

## Install on your phone
- iPhone: open the site in Safari → Share → Add to Home Screen
- Android: open in Chrome → ⋮ → Install app

## Files
- `index.html` – the app
- `drills.js`, `drills_adv.js` – drill data (rep/elite drills in `drills_adv.js`)
- `diagrams.js` – court diagram layouts
- `sw.js` – offline cache (bump `VERSION` on every release)
